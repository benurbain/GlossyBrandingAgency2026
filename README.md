# GlossyBrandingAgency2026

Static HTML hosting via GitHub Pages.

Elke `.html` in de root van `main` is publiek bereikbaar op:

```
https://benurbain.github.io/GlossyBrandingAgency2026/<bestand>.html
```

Voorbeeld: [hello.html](https://benurbain.github.io/GlossyBrandingAgency2026/hello.html)

## Nieuwe pagina publiceren

```bash
git add mijnpagina.html && git commit -m "add mijnpagina" && git push
```

Na ~30–60 seconden staat hij live.
