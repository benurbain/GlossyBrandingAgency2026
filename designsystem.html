01 · Colour

Eight tokens, no more. The palette is essentially black on white; everything else is a tint used for accessible labels, dark-surface metadata, surfaces, hairlines and one accent.

--paper
#ffffff · page ground

--ink
#111111 · body text

--ink-soft
#333333 · secondary prose

--gray
#737373 · labels, meta on light

--gray-on-dark
#b3b3b3 · meta on dark

--smoke
#f3f1f1 · media placeholders

--cream
#fffbe9 · accent, hover wipe

--line
#e2e2e2 · hairlines

Two hairline weights, on purpose. Section dividers use --line; the divider inside an About step uses full --ink. That contrast is deliberate: it is a structural rule, not a separator.

Case section columns come from the CMS, not from the media count. Client tiles set height outright, not via aspect-ratio. max-height: 100% on a logo only resolves against a definite height. With aspect-ratio alone the large marks fell back to intrinsic size and pushed the grid 1180px through the footer. Do not "tidy" this back.

10 · Conventions worth keeping

RuleWhy
Type and gutters are fluid; spacing is notkeeps vertical rhythm predictable while text adapts
No vw-based root font sizethe original scaled off 1vw, which breaks browser zoom
Media paths are stored repo-relativeasset() in the generators, assetUrl() in JS add ../ one level down
Every interactive state has a :focus-visible2px ink outline, 3px offset, globally
Consent is explicit and reversibleaccept and reject carry equal weight; optional scripts and external media stay inert until their category is enabled
Real headings, in orderthe Webflow original had none at all: 321 divs, zero h1–h6
Components fail softno-JS keeps the static logo and no curtain; gated external media remains safely blocked
Resolved system decisions. Display and editorial headings now use explicit weight tokens. --space-xs documents its footer use and the unused --space-3xl token has been removed. Every card, panel and figure radius now resolves through the shared 5px --radius token.
